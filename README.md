# HMRC-MOD29
Extended MOD29 for generating IRIS references, along with calculator for Admin Period income and calculator for multiple CEGs.

## How to use
### IRIS Generator
1. Copy a NINO to your clipboard
2. Press 'CTRL + V' or the button on the calculator Sheet 'Paste NINO + Copy IRIS'
3. Now the IRIS is in your clipboard

### POA Calculator
1. Select the correct tax year using the radio buttons
2. Add the figures to the relevant column <img width="383" height="125" alt="image" src="https://github.com/user-attachments/assets/d9c060de-62a7-4512-a815-d5529af11754" />
3. Once all figures added, go to sheet 'Final Calculation'
4. If SAFE ref is copied to clipboard, press 'Paste SAFE'
   If CREF is copied to clipboard, press 'Paste CREF'
   This allows the note generator to add them automatically, but can be skipped if prefer to add manually
5. Press 'Print Separate Years' to copy a note to clipboard with year by year breakdown of liability
6. Press 'Print Breakdown' to copy a note to clipboard with breakdown by income type

### Multi CEG Calculator
1. Add the gain and Number of years for each Chargeable event
2. The values next to the total will be what to input for multiple CEGs
